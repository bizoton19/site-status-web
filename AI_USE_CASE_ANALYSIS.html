🤖 AI Use Case Analysis

Site Status Monitoring Dashboard

📊 Application Overview

What is this app?

A professional site monitoring dashboard that tracks the uptime and health of multiple websites/endpoints. It polls URLs periodically, stores status history, and provides visualizations for uptime trends, response times, and failure patterns.

Current Features

  • Real-time endpoint status monitoring (OK/Failed)
  • Manual poll triggering via Azure Functions
  • URL management (add, edit, delete monitored sites)
  • Historical data tracking and charts
  • Search and filtering capabilities
  • Microsoft Azure AD authentication
  • Uptime and response time visualizations

Technology Stack

Frontend Vue 3 + Vite
Backend Azure Functions
Storage Azure Table Storage
Auth MSAL (Microsoft)
UI Framework Bootstrap 5
Charts Chart.js

🧠 Recommended AI Models by Use Case

Anomaly Detection Isolation Forest / LSTM Autoencoder

Type: Unsupervised Machine Learning

Best For: Detecting unusual response times, irregular patterns

✅ Pros
  • No labeled data needed
  • Works with small datasets
  • Fast predictions (< 100ms)
  • Python libraries readily available (scikit-learn)
❌ Cons
  • Requires tuning sensitivity
  • May produce false positives initially
  • Needs periodic retraining
Implementation Steps:
  1. Data Collection: Export 2-4 weeks of response time + status history from Azure Table Storage
  2. Feature Engineering: Calculate rolling averages, standard deviations, time-of-day patterns
  3. Model Training: Train Isolation Forest model using scikit-learn (Python)
  4. Integration: Create Azure Function to score new data points in real-time
  5. UI Alert: Add "Anomaly Detected" badge in StatusGrid component when score exceeds threshold

💰 Cost Estimate

Development: 40-60 hours (2-3 weeks for 1 developer)

Infrastructure: ~$20-50/month (Azure ML or small VM for model serving)

Maintenance: 5-10 hours/month (monitoring, retraining)

Predictive Forecasting Prophet / XGBoost Time Series

Type: Time Series Forecasting

Best For: Predicting outages 1-24 hours ahead

✅ Pros
  • Prophet handles seasonality automatically
  • Good with irregular intervals
  • Easy to interpret predictions
  • Works well with limited data
❌ Cons
  • Requires at least 1-2 months of data
  • Needs feature engineering for best results
  • Predictions are probabilistic (not guarantees)

💰 Cost Estimate

Development: 60-80 hours (3-4 weeks for 1 developer)

Infrastructure: ~$30-80/month

Maintenance: 10-15 hours/month

Natural Language OpenAI GPT-4 / Azure OpenAI

Type: Large Language Model (API-based)

Best For: Natural language queries + incident report generation

✅ Pros
  • No training required (use API directly)
  • Already integrated with Azure
  • Handles complex queries naturally
  • Can generate polished reports
  • Fast to implement (1-2 weeks)
❌ Cons
  • API costs: $0.03-0.12 per query
  • Requires prompt engineering
  • Latency: 2-5 seconds per query
  • Need to structure data properly
Simple Implementation (Using Azure OpenAI):
  1. Setup: Create Azure OpenAI resource (already in Azure ecosystem)
  2. Add Chat UI: Add a search bar: "Ask about your sites..."
  3. Context Injection: Send status history as JSON in prompt
  4. Query Processing: Let GPT-4 interpret and respond
  5. Result Display: Show answer + optionally highlight relevant data

Example Prompt Template:

You are a site monitoring assistant. Based on this data:
{status_history_json}

User asks: "{user_question}"

Provide a concise answer with specific metrics.

💰 Cost Estimate

Development: 20-30 hours (1-2 weeks for 1 developer)

Infrastructure: Pay-per-use (estimated $50-200/month for moderate usage)

Maintenance: 2-5 hours/month
